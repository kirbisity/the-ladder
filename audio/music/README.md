# Music

Placeholder tracks: each file is two seconds of silence, so the game runs and the wiring can be tested.
Replace them with real tracks of the same names (MP3). Each plays once, from the start, when its moment's
cut scene begins, and stops when it ends or when the next track starts.

| File | Plays for |
|---|---|
| `good_ending.mp3` | every retirement ending and the FIRE ending |
| `bad_ending.mp3` | death, homelessness and breakdown endings, and burnout |
| `big_moment.mp3` | promotions, and a company sale that pays out |
| `life.mp3` | positive life moments: a first date, the wedding, a new baby |
| `agi.mp3` | the Super Intelligence Revolution |

Music has its own switch in Settings (on by default), separate from the office sound.
